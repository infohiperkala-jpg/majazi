## ملاحظات فنی
- اطلاعات CRM و کمپین‌ها در هر درخواست با شناسه سازمان محدود می‌شوند؛ اعتبارسنجی تعلق برند، مخاطب و فرصت به همان سازمان انجام می‌شود.
- API کمپین‌ها کانال و وضعیت را از فهرست مجاز می‌پذیرد، بودجه و هزینه/درآمد منفی، شمارنده منفی، کلیک بیش از نمایش، تبدیل بیش از کلیک و بازه زمانی نامعتبر را رد می‌کند؛ Migrationهای کمپین و شاخص‌های عملکرد هنگام راه‌اندازی API اعمال می‌شوند.
- شاخص ROAS برابر درآمد منتسب تقسیم بر هزینه واقعی است؛ CTR برابر کلیک تقسیم بر نمایش و نرخ تبدیل برابر تبدیل تقسیم بر کلیک است. در نبود مخرج، مقدار صفر نمایش داده می‌شود.
- Migrationهای دیتابیس هنگام شروع API اعمال می‌شوند؛ Migration استودیوی محتوا فقط دو جدول جدید و ایندکس‌های مربوط را اضافه می‌کند و داده‌های قبلی را تغییر یا حذف نمی‌کند.\n- استودیوی محتوا کلید AI را فقط از تنظیمات سمت سرور می‌خواند و هیچ endpointی مقدار کلید را برنمی‌گرداند. هر ویرایش یک نسخه جدید ثبت می‌کند؛ تأیید محتوا محدود به Owner/Admin است. انتشار و زمان‌بندی واقعی تلگرام برای محتوای تأییدشده، با انتخاب صریح ربات متصل و شناسه عددی مقصد پیاده‌سازی شده است؛ worker پس‌زمینه صف را هر ۱۵ ثانیه بررسی می‌کند، یک‌بار محتوا را claim می‌کند و وضعیت موفق/ناموفق را ثبت می‌کند؛ لغو زمان‌بندی، محدودیت ۴۰۹۶ نویسه و قفل ویرایش محتوای در صف/منتشرشده نیز اعمال شده است. انتشار خودکار سایر شبکه‌ها هنوز پیاده‌سازی نشده است.
- اعتبارنامه کانال‌ها در پایگاه داده به‌صورت رمز‌شده با Data Protection ذخیره می‌شود؛ کلیدهای رمزنگاری باید روی volume پایدار `/var/lib/majazi/keys` نگهداری و در پشتیبان‌گیری محافظت شوند. API هیچ‌گاه مقدار توکن را برنمی‌گرداند. ثبت اعتبارنامه به‌معنای تأیید اتصال از سوی پلتفرم نیست؛ برای تلگرام دکمه «بررسی اتصال» درخواست رسمی `getMe` را اجرا می‌کند. Instagram Business Login پیاده‌سازی شده اما تا تنظیم `META_APP_ID`، `META_APP_SECRET`، `META_REDIRECT_URI` (مسیر عمومی شامل `/backend-api/api/meta/oauth/callback`) و ثبت دقیق همان Redirect URI در Meta فعال نمی‌شود. state با حافظه موقت یک‌بارمصرف و عمر ۱۰ دقیقه نگهداری می‌شود؛ برای چند نمونه API باید به ذخیره‌سازی توزیع‌شده منتقل شود. اتصال Facebook و دریافت آمار/وب‌هوک هنوز پیاده‌سازی نشده‌اند.
- CI در GitHub Actions شامل restore/build بک‌اند و نصب/build فرانت‌اند است.
- اجرای Docker و آزمون Integration با PostgreSQL هنوز به‌عنوان آزمون مستقل تأیید نشده است.
- پیش از انتشار عمومی باید آزمون‌های خودکار tenant isolation و authorization، مدیریت نشست و ابطال توکن، تأیید ایمیل، بازیابی گذرواژه، محدودسازی نرخ مبتنی بر IP و نگهداری توکن در cookie امن HttpOnly تکمیل شوند.
