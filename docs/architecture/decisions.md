# تصمیم‌های معماری اولیه

- شروع با Modular Monolith برای کاهش پیچیدگی عملیاتی.
- ASP.NET Core Minimal API برای هسته HTTP.
- PostgreSQL و EF Core برای ذخیره‌سازی.
- جداسازی سازمان و برند در مدل داده؛ کنترل دسترسی چندمستاجری باید در لایه کاربرد تکمیل شود.
- Next.js App Router و TypeScript برای پنل فارسی RTL.
- اتصال سرویس‌های خارجی فقط از طریق Adapter و با وضعیت اتصال قابل راستی‌آزمایی.
- اسرار فقط از متغیر محیطی یا Secret Store دریافت می‌شوند.
