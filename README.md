# MAJAZI — مرکز هوشمند بازاریابی و فروش

سامانه چندسازمانی و چندبرندی برای مدیریت بازاریابی، محتوا، ارتباط با مشتری و فروش.

## ساختار
- `backend/`: API مبتنی بر ASP.NET Core 10 و PostgreSQL
- `apps/admin-web/`: پنل مدیریتی Next.js و TypeScript
- `docs/`: معماری و وضعیت توسعه

## اجرای محلی
1. `cp .env.example .env`
2. `docker compose up --build`
3. در فایل `.env` مقدار `JWT_SIGNING_KEY` را با یک مقدار تصادفی محرمانه و حداقل ۳۲ بایت جایگزین کنید؛ این کلید را در Git ثبت نکنید.\n4. پنل: http://localhost:3000
5. API: http://localhost:5080
6. سلامت API: http://localhost:5080/health

API هنگام راه‌اندازی، Migrationهای موجود EF Core را روی PostgreSQL اعمال می‌کند. ثبت‌نام اولیه با ایمیل، گذرواژه قوی و نام سازمان انجام می‌شود؛ کاربر ثبت‌نام‌کننده مالک سازمان خواهد بود. ورود با ایمیل و گذرواژه، توکن JWT یک‌ساعته صادر می‌کند. مسیرهای سازمان و برند فقط برای اعضای همان سازمان در دسترس‌اند؛ ویرایش به Owner/Admin و حذف سازمان به Owner محدود است. برای اجرای محلی خارج از Docker، مقدار `ConnectionStrings:Default` را تنظیم کنید.

## وضعیت
هسته اولیه API، مدل سازمان و برند، Migration دیتابیس و داشبورد فارسی در حال توسعه است. اتصال کانال‌های بیرونی، اتصال کانال‌های بیرونی و عوامل AI تا زمان پیاده‌سازی و آزمون مستقل فعال محسوب نمی‌شوند. احراز هویت JWT و عضویت سازمانی اولیه پیاده‌سازی شده، اما پیش از انتشار عمومی به آزمون امنیتی، محدودسازی نرخ، مدیریت نشست/ابطال توکن و تنظیمات عملیاتی تکمیلی نیاز دارد.
